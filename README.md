# Korzinka Power BI Dashboard

Do'konlar tarmog'ining savdo va foyda ko'rsatkichlarini kuzatish uchun Power BI dashboard.

## Maqsad
Sotuv, foyda, cheklar va reja bajarilishini bir sahifada ko'rsatib,
do'konlar, kategoriyalar va vaqt kesimida tahlil qilish.

## Asosiy ko'rsatkichlar (KPI)
- Jami sotuv va yalpi foyda
- Foyda marjasi (%)
- O'rtacha chek va cheklar soni
- YoY o'sish (%)
- Qaytarish foizi
- Reja bajarilishi (%)
- SKU soni

## Vizualizatsiyalar
- Oylik sotuv dinamikasi va sotuv trendi
- Kategoriyalar bo'yicha sotuv va foyda marjasi
- To'lov turi bo'yicha savdolar soni
- Do'konlar bo'yicha reja bajarilishi
- Hafta kunlari bo'yicha cheklar soni

## Filtrlar
Yil, oy, viloyat, kanal, kategoriya va brend bo'yicha.

## Ishlatilgan vositalar
Power BI (Power Query, DAX, Data Model, Vizualizatsiya)
